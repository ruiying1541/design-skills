## 间距系统的核心：基准单位

设计中所有间距都应是某个基准单位的倍数。最常用的是 **4px 基准** 或 **8px 基准**：

- **8px 基准**：主流选择，适合大多数 UI，间距感知明显
- **4px 基准**：精细场景（图标内边距、文字行内间距）

永远不要出现 7px、11px、13px 这样的「奇怪值」。

---

## 间距 Token 定义

```
spacing-0:   0px
spacing-1:   4px    ← 极小间距，图标内边距
spacing-2:   8px    ← 小间距，同组元素间
spacing-3:   12px   ← 标签内边距
spacing-4:   16px   ← 标准间距，卡片内边距
spacing-5:   20px   ← 元素间分组距离
spacing-6:   24px   ← 模块间距
spacing-8:   32px   ← 大间距，区块分割
spacing-10:  40px   ← 超大间距
spacing-12:  48px   ← 页面顶部留白
spacing-16:  64px   ← 章节级分割
spacing-20:  80px   ← 页面 Section 间距
```

## 间距使用规则

### 内边距（Padding）

| 元素类型 | 推荐内边距 |
|---------|---------|
| 小型按钮 | 水平 12px，垂直 6px |
| 标准按钮 | 水平 16px，垂直 10px |
| 大型按钮 | 水平 24px，垂直 14px |
| 卡片容器 | 16px（移动端）/ 24px（Web）|
| 输入框 | 水平 12px，垂直 10px |
| 模态框 | 24px |
| 页面边距 | 16px（移动端）/ 24-48px（Web）|

### 间距的「亲密性原则」

相关的元素距离近，不相关的元素距离远：

```
标题              ← 与正文间距 8px（关系紧密）
正文内容

                  ← 与下一模块间距 32px（模块分割）
新模块标题
```

## 栅格系统

### 移动端栅格（375px 设计稿）

```
列数：4 列
列宽：自适应
列间距（Gutter）：16px
左右边距（Margin）：16px
```

对于 390px（iPhone 14）设计稿：同上，边距可用 20px。

### Web 端栅格

| 断点 | 视口宽度 | 列数 | 列间距 | 边距 |
|------|---------|------|-------|------|
| xs   | < 640px | 4列  | 16px  | 16px |
| sm   | 640px   | 8列  | 24px  | 24px |
| md   | 768px   | 12列 | 24px  | 32px |
| lg   | 1024px  | 12列 | 32px  | 48px |
| xl   | 1280px  | 12列 | 32px  | 64px |
| 2xl  | 1536px  | 12列 | 32px  | auto（内容最大宽 1280px）|

## 响应式布局规范

组件在不同断点的变化规则：

| 组件 | 移动端 | 平板 | 桌面端 |
|------|-------|------|-------|
| 卡片列表 | 1列 | 2列 | 3-4列 |
| 表单 | 1列 | 2列 | 2-3列 |
| 导航 | 底部 Tab | 侧边栏折叠 | 侧边栏展开 |
| 弹窗 | 底部抽屉 | 居中弹窗 | 居中弹窗 |

## Figma 自动布局设置建议

使用 Auto Layout 时的推荐配置：

```
水平排列元素：
  Direction: Horizontal
  Spacing between items: 8px（同类元素）/ 16px（不同类元素）
  Padding: 16px（外容器）

垂直排列卡片内容：
  Direction: Vertical  
  Spacing between items: 8px（标题与描述）/ 4px（标签组）
  Padding: 16px all sides
```
