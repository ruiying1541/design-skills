## 是什么

Humanizer 是一个便携式 Agent Skill，用于识别并消除文本中明显的 AI 写作痕迹。它会检查内容、语言、格式、语气和节奏，再在不改变原意的前提下重写。

它不是简单地把文字“写口语一点”。核心目标是删除空泛表达、恢复具体陈述，并让句子长短和措辞更接近真实写作。

## 核心能力

- 检查并处理 33 类常见 AI 写作模式
- 删除夸大意义、空泛结论和无来源的权威表述
- 减少公式化三段式、同义词轮换和过度排比
- 清理宣传腔、聊天机器人客套话和多余铺垫
- 调整机械的句子节奏、标题结构和格式习惯
- 使用用户提供的写作样本校准个人语气
- 完成第一轮改写后，再进行一次“明显 AI 生成”审查

## 常见检查项

### 内容层

- 把“具有里程碑意义”“标志着全新时代”等夸张判断改为具体事实
- 删除“专家认为”“研究表明”等没有真实来源的模糊归因
- 避免为了显得深刻而追加 `-ing` 式总结或空泛意义分析
- 把营销式形容词换成可以验证的描述

### 语言层

- 减少“此外、值得注意的是、充分体现、赋能、格局”等高频 AI 词汇
- 直接表达观点，少用“这不仅是 X，更是 Y”之类固定句式
- 避免所有内容都硬凑成三项
- 同一个概念允许重复使用最准确的词，不必不断换同义词

### 风格层

- 避免过量粗体、emoji、破折号和标题式列表
- 删除“让我们深入了解”“下面是你需要知道的”等开场套话
- 避免为了制造节奏而连续使用短句或口号
- 让段落结构服从内容，而不是保留原文的机械形状

## 重要原则

> 改写不能发明原文中不存在的事实、姓名、日期、数字或引用。具体信息必须来自原文或作者补充。

Humanizer 会保留原文的信息和真实立场。遇到缺少细节的内容时，应向作者询问，而不是用看似可信的细节填空。

## 使用示例

```text
请使用 Humanizer 改写下面这段文字，保留事实与核心观点，
删除宣传腔和明显的 AI 写作痕迹：

[粘贴文字]
```

需要匹配个人语气时，可以提供 2–3 段自己的文字：

```text
这是我的写作样本：
[粘贴样本]

请参考它的句子节奏、用词和语气，
改写下面这段 AI 文本：
[粘贴文字]
```

也可以直接处理文件：

```text
请使用 Humanizer 优化 docs/launch-post.md 中的文字。
```

## 安装方式

全局安装：

```bash
npx skills add blader/humanizer --global
```

安装到所有支持的 Agent：

```bash
npx skills add blader/humanizer --global --agent '*'
```

Claude Code 插件：

```bash
/plugin marketplace add blader/humanizer
/plugin install humanizer@humanizer
```

## 建议工作流

1. 读取原文，明确事实、观点、受众和语气。
2. 标记 AI 写作模式，不急着逐句替换。
3. 重新组织内容，让段落服从信息关系。
4. 改写措辞和句子节奏，同时保留原始事实。
5. 对照用户写作样本进行语气校准。
6. 再做一次 AI 味审查，清理第一轮遗留的套路表达。
7. 检查是否无意中添加了新事实或改变了作者立场。
