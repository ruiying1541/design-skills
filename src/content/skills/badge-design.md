## 是什么

勋章 Skill 用于为直播平台、语聊房、社交 App、游戏、活动运营、成就系统、等级系统和收藏图鉴设计独立虚拟勋章。

只需提供主题、档位和风格，它会先提炼参考图或文字需求中的视觉 DNA，再重新组织中心主体、外框、冠饰、两侧装饰、底部托座、材质和光效。

## 核心能力

- 根据主题自动选择勋章类型和构图骨架
- 支持人物、IP、活动 KV、主题元素和多张参考图
- 支持单枚设计、多个差异化方案和完整等级套系
- 支持生成前草图规划，以及生成后的升级与降级
- 自动控制中心主体、结构衔接、主题爆点和视觉动势
- 默认避免乱码、水印、平台 Logo、合集图和四宫格
- 使用高对比纯色或透明背景，保持边缘清晰并方便抠图

## 五类自动路由

### 荣誉王冠型

适合冠军、榜一、殿堂、王者、管理员、年度之星与高付费身份。常用皇冠、王座、狮子、凤凰、权杖、双翼、盾牌和大宝石。

### 主题收藏型

适合节日、联名、城市、童话、旅行、音乐、运动、生日和活动纪念。围绕一个明确主题核心，组织成精品珐琅胸针或收藏纪念章。

### 成就任务型

适合点赞、签到、发帖、评论、销售、创作、探索和首发等行为成就。中心保留一个动作或物件，适合 48–128 px 的小尺寸显示。

### 等级进阶型

适合 B、A、S、SS、SSS、SSSS，或铜、银、金、钻等等级体系。共享同一骨架，通过材质、冠饰、翼展、宝石和光效逐级提升。

### IP 主角型

适合人物、萌宠、玩偶与角色立绘。保留角色最强的 3–5 个识别点，使用头部或半身作为中心主体。

## 标准生成规范

- 默认画幅为 1:1，主体占画布 78%–90%
- 中心主体占内部面积 40%–65%
- 主体优先，外框只负责聚焦、承托和等级识别
- 顶部只保留一个主冠饰
- 两侧结构通常对称，可保留轻微自然差异
- 底部使用铭牌、宝石、托座或主题符号收束
- 未要求文字时，默认不生成文字
- 每次只生成一枚独立勋章

## 四级默认梯度

| 等级 | 结构与密度 | 典型表现 |
| --- | --- | --- |
| L1 初级 | 单层框，约 35% 装饰 | 小型或无冠饰，1–2 颗宝石，低光效 |
| L2 中级 | 双层框，约 55% 装饰 | 小皇冠、短翼或月桂，3–5 颗宝石 |
| L3 高级 | 多层框，约 75% 装饰 | 完整冠饰、中型翼展、底部托座 |
| L4 典藏 | 仪式性结构，90%–100% 装饰 | 大翼、多层金属宝石、精准折射与辉光 |

等级差异不能只靠换颜色或文字。相邻等级必须体现可见升级，同时保持主题、主轮廓和核心符号一致。

## 参考图模式

```text
使用勋章 Skill。参考当前上传图片，提炼主题元素、配色、材质、
构图骨架和光效，重新设计为一枚独立虚拟装扮勋章。
不要机械照搬原图，不要合集、四宫格、文字或水印。
```

多张参考图会自动分配职责：

- 结构参考决定外轮廓和模块位置
- 主题参考决定画什么
- 角色参考决定 IP 识别点
- 风格参考决定怎么画
- 材质参考决定表面质感
- 等级参考决定升级节奏
- 光效参考决定高光与辉光

## 生成后调整

### 升级一级

```text
保持当前勋章的主题、中心主体、主轮廓和风格 DNA，
升级一级。仅增强 3–5 个维度：框层、冠饰、翼展、宝石、材质或光效。
```

### 降级一级

```text
保持当前勋章的主题和基础骨架，降级一级。
减少装饰层数、宝石数量和光效强度，但不能让作品显得廉价或残缺。
```

## 自动质检

生成后自动检查：

1. 是否为单枚独立勋章，而非头像框、海报或资料卡？
2. 中心主题能否一眼识别？
3. 外框、冠饰、两侧结构和底部托座是否完整衔接？
4. 是否存在乱码、多余文字、水印或无关元素？
5. 缩小到 64 px 后是否仍然清晰？
6. 等级差异是否来自结构、材质和光效，而非只换颜色？
7. 背景是否方便抠图，边缘是否清晰？
8. 多方案之间是否有真实的构图和材质差异？
