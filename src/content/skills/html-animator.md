## 是什么

HTML 微动效 Skill 面向已有静态页面，帮助补充动效层次和交互反馈。它会在不破坏原结构的前提下，为页面添加适度动画。

## 适用场景

- 页面加载时的渐入动画
- 卡片 Hover、按钮反馈、滚动触发
- 演示页、落地页、活动页增强
- 让 HTML 输出更接近真实产品体验
