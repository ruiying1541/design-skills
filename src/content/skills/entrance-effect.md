## 是什么

进场特效 Skill 用于生成娱乐社交 App、直播平台和语聊房中的进场装扮资源，例如直播间进场条、昵称进场条、贵族装扮、节日装扮和活动限定资源。

它不是普通横幅或活动 KV，而是放置在 **1:1 透明画布中的横向细长进场资源**。

## 核心能力

- 根据主题、元素、风格、档位和配色自动补全构图
- 规范中部昵称信息承载区，避免透明空条或元素遮挡
- 自动处理左端起势、右侧主题爆点及主题托底
- 用流光、花瓣、星光、水花等建立从左到右的进场动势
- 支持参考图主题、配色、材质和风格转译
- 默认输出透明背景、干净边缘并方便抠图
- 避免活动 KV、网页 Banner、普通按钮和满屏背景光效

## 标准画布

| 项目 | 规范 |
| --- | --- |
| 画布 | 1:1 透明画布 |
| 主体 | 横向细长进场资源 |
| 主体比例 | 约 4:1–6:1 |
| 主体位置 | 居中或略偏下 |
| 主体宽度 | 画布的 85%–96% |
| 主体高度 | 画布的 18%–32% |

不要生成 3:1 大 Banner，也不要让主体铺满整张画布。

## 八层结构

1. **透明画布层**：保留干净透明背景。
2. **信息承载底条层**：建立完整、细长且可读的昵称承载面。
3. **左端起始装饰层**：用轻量元素完成封口和起势。
4. **中部干净昵称区层**：约 70% 保持干净。
5. **右侧主题爆点层**：形成最重要的视觉记忆点。
6. **右侧主题托底层**：让主题物稳定挂接在横条尾端。
7. **横向流光粒子层**：建立从左向右的速度和方向。
8. **干净外轮廓层**：保证透明背景下边缘清晰。

## 昵称区规范

信息承载区必须具备真实上屏的昵称承载能力：

- 有完整底色和规整边界
- 中间干净可读
- 上下可使用双细高光线
- 边缘有描边或外发光
- 底框连续完整，不能断裂
- 允许轻微通透，但不能只有描边或光效

中部约 70% 保持干净，剩余区域可加入低透明纹理、小星光或轻粒子。

## 左右结构衔接

### 左端起势

左端使用爱心、星星、花朵、月牙、小徽章、藤蔓、水浪、冰晶角、音符或金属扣件等轻量元素，完成横条起点和封口。

### 右侧主题爆点

右侧主题物必须挂在横条尾端，横条需要穿入、托住或连接主题物。主题爆点宽度约占整体的 25%–38%，高度约为信息条的 1.5–2.8 倍。

### 右侧托底

根据主题选择光环、云雾、水波、花丛、草地、小舞台、金属底座、魔法阵、冰晶、藤蔓或星盘，让主题物与横条成为一个整体。

## 横向动势

动势遵循：

```text
左端起势 → 中部拖尾 → 右侧爆发
```

可使用横向高光线、速度线、流光拖尾、星光、花瓣、水花、音符、彩带、金粉、冰晶或叶片。

粒子应沿横条上下边缘与运动轨迹分布，不要满屏乱飞，也不能遮挡中部昵称区。

## 档位选择

### 低档

- 完整细长信息条
- 轻量左端装饰
- 右侧一个简单主题道具
- 少量粒子，结构清晰

### 中档

- 信息条材质更明确
- 右侧使用主题道具组合或小场景
- 适量流光粒子
- 适合节日活动和普通付费资源

### 高档

- 强材质信息底框
- 高识别度主题爆点
- 可加入人物、IP、萌宠、舞台、建筑或法阵
- 托底和光效更完整，但昵称区仍须干净

用户没有指定档位时，默认使用中档。

## 常用风格

- **Q 版**：圆润、萌系、软糖质感、形体简化
- **乙女**：花饰、丝带、宝石、蕾丝和柔和高光
- **二次元**：清晰线条、幻想感、明亮配色和干净光效
- **国潮节日**：传统符号、金色描边、祥云、水波和饱和配色
- **暗黑幻想**：暗红黑紫、荆棘、羽翼、玫瑰和能量光
- **冰雪梦幻**：冰蓝、雪花、冰晶、水晶和冷光
- **霓虹派对**：舞台、音符、荧光粉蓝紫和音乐速度感
- **乙女植物**：花藤、蝴蝶、精灵、仙兽和花园托底

## 参考图模式

上传参考图后，先分析：

- 主题与代表元素
- 信息条形状
- 左端起势装饰
- 中部净区比例
- 右侧主题爆点
- 右侧托底结构
- 配色和材质
- 动势方向和档位

再重新组织为标准进场装扮结构，保留主题、配色、材质和风格，但不要机械照搬原图构图。

```text
昵称区要有完整底色；左端轻量起势；右侧主题爆点挂在横条尾端；
整体像直播平台进场资源，不要 3:1 Banner。
```

## 自动质检

1. 是否使用 1:1 透明画布？
2. 主体是否为横向细长资源？
3. 昵称区是否有完整底色并干净可读？
4. 左端是否有轻量起势装饰？
5. 右侧主题爆点是否连接横条尾端？
6. 主题物下方是否有合理托底？
7. 粒子和光效是否沿横向运动？
8. 是否没有文字、水印、黑边、白边或脏边？
9. 是否像真实直播平台进场资源，而不是活动 KV 或网页 Banner？
