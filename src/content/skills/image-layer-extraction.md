**版号：v2.2**  
**更新重点：新增「KV / 插图背景固定单独一张」规则，并保留宽高比锁定规则。**

---

## 一、Skill 定位

本 Skill 只用于：

> 将一张参考图拆成可复用的独立设计素材。

输出目标不是海报，不是展示板，不是预览图，而是：

- 可复用元素
- 可抠图素材
- 可做二次设计的资源

适合拆：

- 活动 KV
- 电商主视觉
- UI 插图
- 装饰边框
- 角色 / 道具
- 标题字
- 礼盒 / 盲盒 / 购物车
- 节日元素
- 背景图

---

## 二、版本升级说明

### v2.2 新增重点

1. **背景固定单独一张**：只要是 KV / 插图 / 海报 / 场景图 / 主视觉图，且存在完整背景环境，背景必须固定单独输出一张。  
2. **背景补全更明确**：背景单独拆出时，必须补全被主体遮挡的位置，输出完整底图。  
3. **宽高比锁定继续保留**：KV / 插图类拆图结果必须保持与原图一致的宽高比。  
4. **分层逻辑更清晰**：背景先拆，再拆主体与装饰，不再背景混组。  

### 延续保留的能力

1. **更稳定**：固定拆图流程，减少随机发挥。  
2. **更精准**：先识别结构，再拆元素，不直接乱拆。  
3. **更干净**：输出结果优先用于后期设计，避免展示板思路。  
4. **更适合抠图**：默认输出纯色抠图底。  
5. **更会补全**：对被遮挡元素做合理补全。  
6. **更适合批量工作**：明确分组规则、失败判定、重试规则、输出规范。

## 三、统一输出模式

### 默认输出模式

> **纯色抠图底 PNG**

默认不以“透明图层”作为主要交付方式，而是以更稳定、更便于后期处理的纯色抠图底形式输出。

### 默认背景色规则

- 默认：**纯绿色背景**
- 如果元素本身偏绿色：改用 **纯洋红背景**
- 如果元素本身既有大量绿色又有大量洋红：改用 **纯黑或纯白高对比背景**

### 背景要求

- 必须为单一纯色
- 不能渐变
- 不能纹理
- 不能棋盘格
- 不能展示板
- 不能标题标签

## 四、固定拆图流程

### Step 1：识别图片结构
先判断图中有哪些层级：

- 背景层
- 主体层
- 前景层
- 装饰层
- 文字层
- 光效层

### Step 2：识别可复用元素
只拆有复用价值的元素，例如：

- 边框
- 礼盒
- 角色
- 购物车
- 标题字
- 星星
- 飘带
- 图标
- 装饰花
- 背景底图

### Step 3：判断元素类型
将元素分为：

#### A. 核心主体
- 主购物车
- 礼盒
- 盲盒
- 宝箱
- 角色
- 边框主体

#### B. 结构底板
- 背景图
- 面板
- 圆台
- 舞台
- 背景框

#### C. 大装饰
- 飘带
- 大星星
- 大花
- 大翅膀
- 大爱心

#### D. 小装饰
- 小礼物
- 小图标
- 小爱心
- 小星星
- 小挂件

#### E. 标题文字
- 主标题
- 副标题
- 装饰字
- 单独拆分的字或词（如“啦”“NEW”“SALE”）

### Step 4：判断哪些要补全
分清：

- 可以直接拆
- 需要补全
- 适合重绘
- 不建议硬抠

## 五、分组规则（强约束）

为保证质量：

> **每张图最多 4 个元素**

### 分组数量规则

- **1–4 个元素：1 组**
- **5–8 个元素：2 组**
- **9–12 个元素：3 组**
- 超过 12 个元素时继续顺延，每组最多 4 个

### 分组优先级

#### 第 1 组：背景（仅限 KV / 插图 / 海报 / 场景图 / 主视觉图）
只要有完整背景环境，背景必须固定单独一张。

#### 第 2 组：核心主体
优先放最重要的元素。

#### 第 3 组：结构底板 / 大装饰
如背景框、平台、背景结构、大装饰等。

#### 第 4 组：小装饰 / 小图标 / 补充元素
把零散资源单独整理。

### 特殊规则
如果用户明确说：

- “背景单独一张”
- “标题单独拆”
- “角色单独一组”
- “只拆主要可复用元素”

则优先按用户指定方式分组与筛选。

## 六、补全规则（更精准）

### 1）结构补全
适合：

- 边框
- 圆台
- 背景板
- 面板
- 箱子
- 礼盒

要求：
补齐被挡住的边缘，让元素完整闭合。

### 2）装饰补全
适合：

- 花瓣
- 翅膀
- 飘带
- 叶片
- 星星装饰

要求：
顺着现有样式补齐，不乱生成。

### 3）对称补全
适合：

- 左右成对结构
- 左右耳朵 / 翅膀 / 装饰件
- 左右边框

要求：
参考另一侧，保持视觉统一。

### 4）重绘补全
适合：

- 被挡住太多
- 原图信息不足
- 需要作为独立素材反复复用

要求：
保持风格一致，重建完整单元素。

## 七、KV / 插图专用：背景固定单独一张（v2.2 新增硬性规则）

对于以下类型图片：

- KV
- 插图
- 海报
- 场景图
- 主视觉图
- 明显带完整背景环境的画面

拆图输出必须满足：

> **背景固定单独输出一张**

### 具体要求

1. 先识别图片是否包含完整背景环境。  
2. 只要存在可复用背景，背景必须单独成图。  
3. 背景图中不得混入人物、主体、道具、标题等主要元素。  
4. 背景图需要补全被主体遮挡的区域，形成完整底图。  
5. 背景图必须保持与原图一致的宽高比。  
6. 其余元素再按每组最多 4 个元素继续分组。  
7. 如果用户没有特别说明，KV / 插图类拆图默认启用“背景单独一张”规则。  

### 示例

#### 示例 A：人物 + 龙舟 + 背景
输出应为：
- 第 1 张：背景
- 第 2 张：人物
- 第 3 张：龙舟

#### 示例 B：KV 主视觉 + 标题 + 礼盒 + 背景
输出应为：
- 第 1 张：背景
- 第 2 张：标题
- 第 3 张：礼盒或主体元素

---

## 八、KV / 插图专用：宽高比锁定规则（保留）

对于以下类型图片：

- KV
- 插图
- 海报
- 场景图
- 主视觉图

拆图输出必须满足：

> **最终输出画布宽高比 = 原图宽高比**

### 具体要求

1. 先识别原图宽高比。  
2. 所有拆图结果继承原图宽高比。  
3. 背景图单独拆出时，必须保持原图比例。  
4. 单个主体元素拆出时，也必须放在与原图相同比例的画布中输出。  
5. 多组拆图时，各组输出比例必须一致，并与原图一致。  
6. 不允许自动改成方图、竖图或其他不相关比例。  
7. 元素需尽量放大，但不得裁切，不得压边。  
8. 宽高比不一致视为失败输出，必须重生。  

---

## 九、失败判定（严格）

以下任一情况都算失败，不能当最终结果交付：

### 背景类失败
- 不是纯色底
- 出现棋盘格
- 出现展示板
- 出现标签 / 文件名 / 标题

### 元素类失败
- 元素被裁切
- 边缘脏
- 元素互相粘连严重
- 本应单独拆的元素合并了
- 补全后结构不完整
- 元素过小，不便使用

### 风格类失败
- 风格明显偏离原图
- 材质错乱
- 配色失真
- 比原图更脏、更碎、更糊

### 宽高比失败
- 原图是横图，输出变成方图
- 原图是宽横版，输出变窄
- 原图是竖版插图，输出被改成横版
- 各组拆图比例不统一

### 背景拆分失败
- 背景没有单独成图
- 背景与主体混在一起
- 背景缺失大量遮挡补全

### 一旦失败
> 必须重新生成，不视为合格拆图。

## 十、最终输出规范

### 图内禁止出现
- 标题
- 标签
- 文件名
- 组名
- 展示板
- 棋盘格
- 说明文案

### 图内必须做到
- 元素独立摆放
- 元素不重叠
- 每组不超过 4 个元素
- 边缘完整
- 背景为纯色抠图底
- 被遮挡部分合理补全
- 可直接进入后期设计流程
- KV / 插图类拆图保持原图宽高比
- KV / 插图类背景固定单独一张

## 十一、推荐标准执行逻辑

以后每次拆图，按以下固定流程执行：

### 第一步：识别要拆的元素
先列出元素清单。

### 第二步：判断图片类型
如果是 KV / 插图 / 海报 / 场景图 / 主视觉图，优先启用“背景单独一张”规则。

### 第三步：识别原图宽高比
若属于视觉类图片，先锁定原图比例。

### 第四步：优先拆背景
背景必须单独成图，并补全遮挡位置。

### 第五步：再拆主体与装饰
其余元素继续按每组最多 4 个元素分组。

### 第六步：确定抠图底颜色
优先选择和元素反差最大的纯色底。

### 第七步：拆图并补全
保证完整性、边缘干净、可复用。

### 第八步：检查结果
不合格就重新生成。

### 推荐说法


## 十五、一句话总结

> **图像拆图技能 2.2 的核心是：先识别结构，再精确拆分可复用元素，按组稳定输出纯色抠图底素材，并对遮挡部分做合理补全；凡是 KV / 插图拆图，背景必须固定单独输出一张，且所有拆图结果严格保持与原图一致的宽高比。**
