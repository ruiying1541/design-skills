AI 调用指南

所有 Skill 都可以通过以下方式被 AI Agent 直接调用：

Step 1读取全量索引
GET https://liruiying.github.io/design-skills/skills-index.json
Step 2匹配 ai_trigger 字段找到合适的 Skill
{
  "name": "color-system",
  "ai_trigger": ["需要为产品建立配色方案"],
  "raw_url": "https://raw.githubusercontent.com/..."
}
Step 3读取 raw_url 获取完整 Skill
GET {raw_url}  →  完整 Markdown Skill 文件
