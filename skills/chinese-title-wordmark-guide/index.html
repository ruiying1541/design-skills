1. 这个 Skill 是做什么的？

这个 Skill 用来生成中文活动标题字、字标、美术字、直播活动标题、社交产品运营标题、游戏活动标题等。

它的核心目标是：

  • 让标题文字准确可读
  • 根据主题设计匹配的字体风格
  • 控制字形结构、笔触、材质、装饰和画质
  • 默认黑色背景，方便后期抠图、比稿和二次使用
  • 支持单个标题、4个方案、多风格探索和参考图风格转译

2. 最基础的使用格式

你可以直接这样下指令：

用 Skill 生成标题字：
标题字：21宠粉节
风格：二次元风格
复杂程度：简单
配色：粉紫
数量：4个标题

也可以更完整一点：

用中文标题字字标设计 Skill 生成：
标题字：装扮盲盒上新拉！
重点：盲盒上新需要突出
风格：可爱的二次元风格
复杂程度：简单
配色：可爱粉紫
数量：4个标题
背景：黑色背景
用途：语聊社交产品活动KV

3. 推荐输入项

每次使用时，建议提供以下信息：

复杂程度 控制元素数量和精细度 简单、中等、华丽、高付费

数量 输出几个方案 1个、4个
背景 默认黑色背景，可特别指定 黑底、透明、白底、KV背景
用途 方便控制商业落地感 直播活动、语聊社交、游戏赛事、活动KV

5. 风格关键词参考

可爱3D风格

适合：盲盒、宠粉节、上新活动、福利活动。

关键词：

圆润字体、软糖质感、粉紫配色、立体泡泡字、礼盒、蝴蝶结、星星、爱心、可爱高光、简单干净

二次元风格

适合：语聊社交产品、活动标题、游戏活动、年轻化运营。

关键词：

动漫感字形、明亮描边、高饱和配色、速度感笔画、星光、音符、彩色光效、清晰轮廓、轻量装饰

乙女风格

适合：女性向活动、CP活动、男团活动、浪漫活动、付费活动。

关键词：

粉金、玫瑰金、珍珠白、蝴蝶结、宝石、羽翼、丝带、爱心、华丽曲线、精致高光、女性向游戏感

华丽赛事风格

适合：巅峰赛、荣耀赛、月赛、年度赛、排行活动。

关键词：

金属浮雕、皇冠、奖杯、神殿柱、宝石、荣耀光效、厚重字体、对称构图、强中心感、赛事仪式感

国风书法风格

适合：节日、传统文化、端午、新年、古风活动。

关键词：

书法笔触、飞白、墨迹、金边、祥云、卷轴、国风纹样、动态笔势、结构张力

6. 黑色背景规则

当前 Skill 默认：

所有标题字默认生成在纯黑或深黑背景上。

这样做的好处：

  • 方便看清标题边缘
  • 方便后期抠图
  • 方便比稿
  • 方便用于KV合成
  • 能更好检查光效、描边和材质

如果你想要其他背景，需要明确说明：

背景改成透明底
背景改成白底
背景改成浅粉渐变
背景改成参考图KV场景

7. 质量要求

生成标题时默认需要满足：

  • 字形准确，不错字、不漏字、不伪字
  • 重点文字突出
  • 边缘清晰，轮廓干净
  • 笔画完整，不断裂、不粘连
  • 材质干净，不脏、不糊
  • 光效克制，不吃字
  • 缩小后仍然可读
  • 适合商业活动上线使用

推荐质量提示词：

crisp clean edges, sharp stroke contours, accurate Chinese character anatomy, complete readable radicals, stable structure, high legibility, polished surface rendering, clean highlights, restrained glow, commercial-grade finish

负面质量提示词：

blurry text, fuzzy edges, broken strokes, collapsed structure, merged radicals, malformed Chinese characters, pseudo-characters, muddy texture, dirty noise, excessive bloom, clutter, illegible lettering

8. 反重复生成规则

每次新指令都不能简单复用上一轮结果。

当你说“重新生成”时，默认需要改变至少3个方面：

  • 字体骨架
  • 构图方式
  • 笔触连接
  • 材质
  • 配色比例
  • 装饰元素
  • 光效强度
  • 整体气质

示例指令：

重新生成4个标题，要求和上一轮完全不同，不要只换颜色，构图、字体骨架、装饰和材质都要变化。

9. 输出检查方式

生成后可以按下面标准检查：

  1. 标题文字是否正确？
  2. 重点文字是否突出？
  3. 字体风格是否符合主题？
  4. 画面是否太复杂？
  5. 边缘是否清晰？
  6. 黑色背景是否干净？
  7. 装饰是否遮挡文字？
  8. 是否适合放进活动KV？

10. 常见修改指令

放大重点文字

把“盲盒上新”放大，装扮和拉！缩小作为辅助。

简化元素

元素太多，改简单一点，只保留礼盒、星星和蝴蝶结。

增强质感

加强字体质感，边缘更清晰，高光更干净，整体更精修。

改成更乙女

改成更乙女风，增加粉金、宝石、丝带、蝴蝶结，但不要太复杂。

改成更二次元

改成更二次元活动标题，增加明亮描边、动漫感高光、轻微速度感。

去掉复杂背景

只保留标题字和少量装饰，黑色背景，不要场景。

11. 推荐工作流

第一步：先出4个方向

用 Skill 生成4个“21宠粉节”标题字，语聊社交产品，二次元风格，黑色背景。

第二步：选一个方向

选第2个方向，继续优化。

第三步：做精修

保持整体风格不变，优化字体清晰度、边缘、材质和重点文字层级。

第四步：做适配

生成适合放进3:1活动KV的版本，标题居中，左右留安全边距。

12. 最推荐的万能指令

用中文标题字字标设计 Skill 生成：
标题字：【填写标题】
重点：【填写重点文字】
风格：【填写风格】
复杂程度：【简单 / 中等 / 华丽 / 高付费】
配色：【填写配色】
数量：【1个 / 4个】
背景：黑色背景
用途：【活动KV / 语聊社交 / 直播活动 / 游戏赛事】

要求：
1. 标题文字准确，不错字、不漏字、不伪字；
2. 重点文字需要明显突出；
3. 字体边缘清晰，轮廓干净，材质精修；
4. 装饰元素不能遮挡文字；
5. 如果生成4个方案，4个方向需要明显不同，不能只换颜色。
