排版规范

视觉生成入门

建立产品字体系统，涵盖字号层级、行高、字重、字间距和中英文排版规则，让信息层次一目了然。

#字体#排版#字号#行高#设计系统#文字规范updated 2026-07-03
## 为什么需要排版规范？

随意的字号会让界面显得混乱，用户无法快速扫描信息层级。一套好的排版规范能做到：

- 用户 3 秒内看清页面主次结构
- 团队内所有设计师用相同的字号系统
- 开发直接引用 token，无需猜测字号值

---

## Type Scale（字号梯度）

推荐使用基于**模块比例**（Modular Scale）的字号系统，常见比例：1.25（Major Third）或 1.333（Perfect Fourth）。

### 移动端推荐字号层级

| Token | 字号 | 行高 | 字重 | 用途 |
|-------|------|------|------|------|
| `text-xs` | 11px | 16px | 400 | 辅助说明、时间戳 |
| `text-sm` | 13px | 18px | 400 | 描述文字、副标题 |
| `text-base` | 15px | 22px | 400 | 正文内容 |
| `text-md` | 17px | 24px | 500 | 列表标题、按钮文字 |
| `text-lg` | 20px | 28px | 600 | 卡片标题、模块标题 |
| `text-xl` | 24px | 32px | 600 | 页面主标题 |
| `text-2xl` | 28px | 36px | 700 | Banner 大标题 |

### Web 端推荐字号层级

| Token | 字号 | 行高 | 用途 |
|-------|------|------|------|
| `text-xs` | 12px | 16px | 标签、角标 |
| `text-sm` | 14px | 20px | 辅助说明 |
| `text-base` | 16px | 24px | 正文 |
| `text-lg` | 18px | 28px | 卡片标题 |
| `text-xl` | 20px | 28px | 模块标题 |
| `text-2xl` | 24px | 32px | 页面 H2 |
| `text-3xl` | 30px | 40px | 页面 H1 |
| `text-4xl` | 36px | 44px | Hero 标题 |

---

## 字重使用规范

字重不是用来「强调」的，而是用来定义层级的。

| 字重 | 值 | 适用场景 |
|------|-----|---------|
| Regular | 400 | 正文、描述、标签 |
| Medium | 500 | 次级标题、按钮、导航 |
| Semibold | 600 | 主标题、重要数据 |
| Bold | 700 | Banner、极强调场景 |

> 避免在同一区域大量使用 Bold，会导致「到处都是重点，等于没有重点」。

---

## 行高规范

行高（line-height）直接影响阅读舒适度：

- **标题类**：行高 = 字号 × 1.2～1.3（紧凑，视觉有力）
- **正文类**：行高 = 字号 × 1.5～1.6（舒适，便于阅读）
- **多行标签**：行高 = 字号 × 1.4

---

## 中文排版特殊规则

1. **中文不使用斜体**：中文斜体渲染效果差，不用于强调
2. **中英文之间加空格**：「设计 Token」比「设计Token」更专业
3. **全角标点**：中文句子用 `，。！？` 而非 `,. ! ?`
4. **数字和单位**：使用半角数字 `16px` 而非 `１６px`
5. **最小可识别字号**：移动端不小于 10px，Web 端不小于 12px

---

## 字体选型建议

### 中文
- 系统字体栈：`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"`
- 自定义：阿里巴巴普惠体（免费商用）、思源黑体（Google 免费）

### 英文
- 无衬线（UI 首选）：Inter、SF Pro Text、Geist
- 等宽（代码）：JetBrains Mono、Fira Code

---

## AI 辅助使用

AI 可以帮助你：

1. **生成完整 Type Scale**：给 AI 基准字号，它生成整套字号梯度和 token
2. **审查排版问题**：给 AI 截图，它指出行高过密/字号层级不清的问题
3. **中英文混排检查**：AI 可以扫描文案中的中英文间距问题

**触发词示例：**
> "帮我基于 16px 为基准字号，用 1.25 的模块比例生成移动端完整 Type Scale，包括每个层级的用途说明和 Figma token 命名"
