## 是什么

中东主题头像框 Skill 用于生成适合社交 App、语聊 App、直播平台、游戏活动和装扮商城的头像框资源。

它会把主题、等级、风格、元素和参考图转译成稳定的环形视觉容器，并重点控制中心头像区、外圈装饰、材质层级和小尺寸识别度。

## 核心目标

- 中心头像区域保持清晰、无遮挡
- 外轮廓完整，小尺寸下仍能识别
- 主题元素形成 1–3 个明确记忆点
- 金属、宝石、玻璃和织物材质层次清楚
- 装饰华丽但不破坏头像容器功能
- 使用纯色背景，方便后续抠图和资源切割

## 中东主题视觉语言

### 推荐元素

- 新月、星星、神灯和阿拉丁油灯
- 阿拉伯宫殿、拱门、尖顶与宣礼塔
- 中东灯笼、流苏、珠链和装饰吊坠
- 皇冠、宝石、金属花纹和几何纹样
- 云雾、星轨和柔和魔法光点

### 推荐配色

- 宝蓝 + 金色：经典、荣耀、夜空感
- 紫色 + 香槟金：梦幻、浪漫、女性向
- 祖母绿 + 金色：宫廷、贵族、节日感
- 深蓝 + 月光金：神秘、夜晚、开斋节氛围

### 推荐材质

- 抛光黄金、珐琅金边和雕花金属
- 蓝宝石、紫水晶和祖母绿切面
- 透明玻璃、柔和辉光和细小星点
- 丝绸、流苏、珠链和云雾

## 头像框结构规范

### 中心留白

- 中心留白约占画面的 55%–70%
- 不能让灯笼、宫殿、神灯和宝石大面积伸入头像区
- 头像区域必须保持完整圆形或接近圆形
- 光效只沿边缘出现，不覆盖头像主体

### 视觉层级

1. **外轮廓层**：用拱门、月牙、云雾或金属弧线建立整体轮廓。
2. **主框架层**：形成稳定、连续的金属或宝石环。
3. **主题装饰层**：将神灯、灯笼、宫殿和宝石放在顶部、底部或两侧。
4. **光效层**：在宝石切面、金属转折和月牙边缘添加高光。

### 对称与破对称

- 主框架保持稳定对称
- 顶部宝石或拱门形成视觉起点
- 底部神灯、宫殿或云雾形成视觉落点
- 灯笼、流苏和星点可以轻微破对称

## 等级选择

### 低价款

- 简单圆环或月牙结构
- 1 个主元素 + 2–4 个小点缀
- 2–3 种主色
- 轻量金边和少量光效

### 中价款

- 完整圆环、半开放圆环或宫殿拱门结构
- 1–2 个主元素 + 4–8 个辅助点缀
- 金属、宝石与云雾形成清晰层次
- 适合活动限定和常规付费资源

### 高价款

- 多层金属框、宝石镶嵌和复杂宫廷纹样
- 顶部、底部和两侧形成完整装饰系统
- 加入精细灯笼、珠链、流苏和魔法光效
- 付费感强，但中心仍须保持干净

用户没有指定等级时，默认按中价款执行。

## 标准生成指令

```text
使用中东主题头像框 Skill。

主题：中东神灯
等级：中价款
风格：3D 金属宝石风
数量：4 个
元素：新月、中东灯笼、阿拉丁神灯、宫殿拱门、星星、宝石
配色：宝蓝、紫色、祖母绿与金色
背景：纯黑背景，方便抠图

要求：
中心头像区留白完整；
装饰集中在外圈；
金属轮廓和宝石切面清晰；
每款构图和配色有区别，但属于同一套系；
不要人物、文字、水印和复杂场景背景。
```

## 一句话使用

```text
生成 4 个中东神灯主题头像框，中价款，3D 金属宝石风，
使用新月、灯笼、神灯、宫殿和宝石元素，纯黑背景，方便抠图。
```

## 参考图模式

上传参考图时，先分析：

- 主题与情绪
- 主色和辅助色
- 代表元素
- 金属、宝石、玻璃或织物材质
- 圆润、尖锐、华丽或简洁的轮廓语言
- 柔光、强闪、梦幻或清透的光效

再把参考图转译成头像框：

- 保留主题元素和风格 DNA
- 把拱门、月牙、花纹和光轨转化为环形框架
- 背景场景只保留少量粒子、纹样或颜色氛围
- 不能直接照搬原图构图

## 返工指令

### 中心被遮挡

```text
中心头像区域被装饰遮挡，请把神灯、灯笼、宫殿和宝石移到外圈，
恢复完整的圆形留白。
```

### 质感不够

```text
升级金属和宝石质感：增加抛光金属的明暗转折、宝石切面折射和局部高光，
但不要增加无关元素。
```

### 主题不统一

```text
只保留中东神灯主题元素，统一为宫殿拱门、月牙、灯笼、神灯和宝石，
删除与主题无关的装饰。
```

### 不方便抠图

```text
删除复杂场景和大面积光雾，改为纯黑背景；
保持头像框外轮廓清晰，不要阴影粘连。
```

## 自检清单

1. 是否是头像框，而不是海报、徽章或场景插画？
2. 中心头像区是否完整、干净、无遮挡？
3. 外轮廓是否闭合或形成稳定的半开放结构？
4. 新月、灯笼、神灯、宫殿和宝石是否属于同一视觉系统？
5. 金属和宝石材质是否有清晰层级？
6. 主装饰是否集中在顶部、底部或两侧？
7. 小尺寸下是否仍能识别主题？
8. 是否使用纯色背景并方便抠图？
9. 是否没有人物、文字、水印、乱码和多余标签？
10. 四款方案是否有变化，同时保持同套系？
