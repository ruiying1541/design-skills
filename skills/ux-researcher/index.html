UX 研究设计

研究洞察进阶

用户调研 + 设计改进一条龙。涵盖用户研究方法论、可用性测试、用户旅程映射、信息架构规划、设计决策文档化。

#用户研究#可用性测试#用户旅程#信息架构#调研方法updated 2026-07
## 是什么

UX Researcher Designer Skill 将用户研究方法论嵌入 AI，让你不需要是专职研究员，也能产出专业水准的研究报告。

覆盖从「问题发现」到「设计改进」的完整研究闭环。

## 核心能力

### 用户研究方法论
根据你的研究目标，推荐最适合的研究方法：

| 研究目标 | 推荐方法 |
|----------|----------|
| 了解用户行为原因 | 深度访谈 |
| 发现可用性问题 | 可用性测试 |
| 验证方案有效性 | A/B 测试 |
| 快速获取用户反馈 | 问卷调查 |
| 观察真实使用场景 | 情境调查 |

### 访谈问题生成
输入研究主题，自动生成：
- 开场问题（建立信任）
- 探索性问题（发现规律）
- 追问模板（深挖细节）
- 避免引导性的中立问法

### 调研数据整理
上传访谈记录，自动输出：
- 高频痛点（按出现次数排序）
- 用户情绪关键词
- 改进机会点
- 可量化的优先级矩阵

### 用户旅程地图（HTML 版）
输入核心流程，生成可视化旅程地图：

```
包含：
- 用户每步行为
- 情绪曲线（1-10 评分）
- 痛点标注（红色）
- 机会点标注（绿色）
- 负责团队标注
```

### 可用性测试
生成完整测试方案：
- 测试目标定义
- 任务脚本（5-7 个任务）
- 观察记录表格
- 问题严重性分级（P0/P1/P2）
- 改进建议优先级

### 信息架构规划
- 卡片分类法（Card Sorting）分析
- 树形测试（Tree Testing）设计
- 导航结构优化建议
- 内容分类标签体系

## AI 调用示例

```
使用 UX Researcher Designer，帮我整理这次用户访谈：

访谈主题：设计师使用 AI 工具的工作流程
访谈人数：8 人
访谈记录如下：[粘贴文字稿]

输出要求：
1. 提炼每位用户的核心痛点（一句话）
2. 统计高频问题（出现 3 次以上）
3. 按「效率/质量/协作/学习」四类归因
4. 给出改进机会点优先级排序
```
