HTML 微动效

组件打磨进阶

为静态 HTML 页面注入微交互与动画，包括淡入淡出、滚动触发、悬停反馈等，提升页面活力与专业感。

#HTML#动效#微交互#CSS 动画#页面增强updated 2026-07
## 是什么

HTML 微动效 Skill 面向已有静态页面，帮助补充动效层次和交互反馈。它会在不破坏原结构的前提下，为页面添加适度动画。

## 适用场景

- 页面加载时的渐入动画
- 卡片 Hover、按钮反馈、滚动触发
- 演示页、落地页、活动页增强
- 让 HTML 输出更接近真实产品体验

## 测试指令

```text
帮我给这个 HTML 页面增加微动效，包括卡片入场、按钮 hover 和滚动触发动画
```
