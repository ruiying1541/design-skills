流程图与思维导图

研究洞察入门

输入内容描述或大纲，自动梳理逻辑关系，生成结构清晰的流程图或思维导图。

#流程图#思维导图#结构化#信息架构#逻辑梳理updated 2026-07
## 是什么

流程图与思维导图 Skill 可以把文字描述、大纲、业务逻辑或策略内容转成结构化图形，帮助团队快速理解关系、步骤和分支。

## 适用场景

- 用户流程、业务流程、异常分支梳理
- 产品策略、增长策略、项目规划
- 知识结构、课程大纲、研究框架
- 把复杂文本转成可视化结构

## 测试指令

```text
虚拟数据：新用户注册流程（填写信息 → 同意协议 → 手机号去重检查 → 验证码发送与校验 → 创建账号 → 跳转欢迎页，含两条异常分支）
```
