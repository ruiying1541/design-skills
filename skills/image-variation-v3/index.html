图片裂变 Skill v3.0

视觉生成高阶
一键下载 Skill

基于参考图锁定视觉 DNA，使用 GPT Image 进行主题、材质、等级、名次、人物 IP 与拟人物体 IP 裂变，并自动检查数量、风格和结构一致性。

#图片裂变#参考图#IP设计#等级体系#材质转译updated 2026-08

1. 定位

本 Skill 不是随机生成多个相似方案，而是把一张参考图稳定延展为一套风格统一、差异明确、数量准确、可商业上线的独立视觉资产。

核心目标：

  1. 提取并保留参考图真正有价值的设计 DNA；
  2. 先建立统一风格母体，再改变主题、主体、材质、构图或等级；
  3. 所有结果同系列但不重复；
  4. 用户要求几张，就生成几张独立图片；
  5. 出现宫格、风格漂移、角色变脸等问题时自动重做当前张。

2. 唯一生图工具

所有生成、重绘、修复和裂变只能使用 GPT Image。

禁止：Midjourney、Stable Diffusion、ComfyUI、第三方 API，以及用文字假装已经完成生图。

数量 4 的正确执行流程：

第1张独立生成 → 检查
第2张独立生成 → 检查
第3张独立生成 → 检查
第4张独立生成 → 检查

禁止合集图、三联图、四宫格、资产展示板、对比排版、编号说明图。

3. 自动路由

收到任务后自动识别一个主裂变维度：

  • 主题裂变：主体和风格不变，改变世界观、专属元素、动作与情绪；
  • 主体裂变：风格、构图骨架与材质不变，替换主视觉主体；
  • 材质裂变：主体、主题、构图不变，改变表面、厚度和光学表现；
  • 构图裂变：主题与主体不变，改变视觉重心、动线、层级和空间组织；
  • 等级裂变：生成高、中、低等连续等级；
  • 名次裂变：生成冠军、亚军、季军；
  • 人物 IP 裂变：先提炼稳定角色识别点，再做主题或材质延展；
  • 拟人物体 IP 裂变：将物体功能转化为人格、五官、动作和世界观；
  • 资源类型裂变：把同一设计 DNA 延展为头像框、勋章、称号条、资料卡等资产。

多个维度同时出现时，只允许一个维度做大幅变化，其他维度作为辅助控制，避免风格失控。

4. 自动前置：风格锚定

只要用户上传参考图，或出现风格、画风、材质、同套系、统一风格、C4D、毛绒、二次元、乙女、Q版等要求，必须先执行风格锚定。

4.1 风格母体

每次只设定：

  • 1 个主风格；
  • 最多 3 个辅助特征；
  • 明确冲突风格和禁止项。

4.2 风格指纹八维

必须明确：

  1. 形体；
  2. 轮廓；
  3. 色彩；
  4. 上色；
  5. 光影；
  6. 材质；
  7. 构图；
  8. 细节密度。

至少 3 个维度必须与其他风格明显不同。

4.3 优先级

用户明确风格要求
> 用户上传的风格参考图
> 上一轮已确认风格母体
> 当前参考图可提取的视觉语言
> 模型默认审美

风格锚定只控制“怎么画”，不能擅自改变“画什么”。

5. 设计 DNA 分析

裂变前先提取：

核心识别

  • 主体；
  • 一眼可认的轮廓；
  • 必须保留的主题符号；
  • 视觉爆点。

结构骨架

  • 外轮廓；
  • 顶部主装饰；
  • 左右辅助结构；
  • 底部承接；
  • 中央留白或内容区；
  • 主要动线与层级。

风格语言

  • 配色比例；
  • 材质组合；
  • 光源方向；
  • 高光类型；
  • 体积感；
  • 边缘处理；
  • 细节密度。

可变与不可变

不可变：核心身份、主风格、核心结构、关键识别符号、资产功能
可变：主题元素、材质、配色、装饰数量、动作、情绪、等级复杂度

6. 人物与拟人物体 IP 裂变

6.1 人物 IP 最低识别标准

每个角色至少固定：

  • 1 个头部符号；
  • 1 个服装符号；
  • 1 个固定配色；
  • 1 个固定表情或情绪；
  • 1 个小伙伴、道具或标志图形。

必须锁定脸型、眼型、发型剪影、服装和标志物，禁止每张换脸。

6.2 卡通化规则

用户要求“不要太真人、夸张五官、卡通化”时：

  • 头大身短；
  • 扁圆脸；
  • 眼睛放大并固定眼型；
  • 鼻子弱化；
  • 嘴型简化；
  • 手脚缩短；
  • 轮廓圆润；
  • 降低真实皮肤纹理；
  • 增强毛绒、搪胶、软陶或潮玩感；
  • 禁止写实毛孔、真实摄影脸和成人比例。

6.3 拟人物体逻辑

不能只给物体加眼睛和手脚，必须完成：

物体功能 → 性格 → 行为 → 五官位置 → 肢体结构 → 情绪 → 标志动作 → 世界观

主题元素必须与角色形成内在关系，禁止机械贴图。

7. 等级裂变 v3.0

高、中、低必须连续递减：

高级：100%
中级：75%–85%
低级：45%–55%

高级款

  • 结构最完整；
  • 装饰最多；
  • 材质最丰富；
  • 光效和体积感最强；
  • 稀有感与仪式感最强。

中级款保护机制

中级款必须是完整商业主流版，保留：

  • 高级款核心骨架；
  • 顶部主装饰；
  • 主要侧边结构；
  • 底部承接；
  • 主宝石或主符号；
  • 中等偏上的材质完成度。

禁止只剩一圈框、像残缺版、或过度接近低级款。

低级款

  • 保留核心识别；
  • 保留完整基础框架；
  • 减少装饰、材质层级和光效；
  • 仍然必须是可上线成品。

8. 名次裂变

默认映射：

冠军 → 金
亚军 → 银
季军 → 铜

用户指定优先。

冠军最完整、最尊贵；亚军保留约 80% 的结构与完成度；季军收缩外轮廓并减少辅装饰，但必须保持同一主体、骨架和主题。

9. 材质裂变

材质变化必须体现在表面、厚度、边缘、反射和光学行为，而不是只换颜色。

C4D / 搪胶

平滑表面、清晰倒角、棚拍高光、接触阴影、真实体积。

毛绒 / 毛毡

短绒纤维、缝线、填充体积、柔软边缘、漫反射；禁止塑料镜面高光。

透明塑料 / 水晶

透光、折射、边缘高光、内部厚度和接触阴影；禁止透明贴纸感。

软陶 / 黏土

手工捏塑、轻微不规则、哑光表面、圆润体积；禁止玻璃反射。

10. 主题裂变

不同主题至少改变 4 项：

  • 核心意象；
  • 专属道具；
  • 角色动作；
  • 场景语义；
  • 配色比例；
  • 装饰形状；
  • 光效类型；
  • 情绪关键词。

禁止只改颜色。

情侣主题示例应区分月光誓约、深海共生、星河婚礼、蝶梦花园等不同专属事件和高潮符号。

11. 数量锁定

数量：3 = 3 张独立图片
数量：4 = 4 张独立图片

顺序锁定

高、中、低 → 第1张高，第2张中，第3张低
冠军、亚军、季军 → 第1张冠军，第2张亚军，第3张季军

材质、主题、主体按用户列出的顺序逐张生成。

12. 单张提示词结构

每张图使用独立提示词：

风格锁定句
→ 设计 DNA 保留项
→ 本张裂变方向
→ 主体与结构
→ 材质与光影
→ 构图与安全区
→ 画幅与背景
→ 画质修复
→ 负面约束

通用负面约束：

不要合集图，不要多宫格，不要方案展示板，不要编号说明，不要水印，不要品牌Logo，不要多个版本同时出现，不要文字乱码，不要结构断裂，不要多余肢体，不要风格漂移，不要完整照搬参考图。

13. 生成后自动检测

每张生成后检查：

数量

  • 是否只有一个独立成品；
  • 是否误生成多个版本；
  • 是否出现宫格或合集。

风格

  • 是否继承同一风格母体；
  • 是否突然变成不相关风格；
  • 材质是否符合要求。

结构

  • 主体是否完整；
  • 外轮廓是否清楚；
  • 安全区是否正确；
  • 是否断裂、粘连或裁切。

IP

  • 脸型、眼型、发型、服装、标志物是否一致；
  • 是否仍然是同一个角色。

等级

  • 中级是否完整；
  • 高与中是否差距过大；
  • 中与低是否难以区分；
  • 三档是否同系列。

14. 自动纠错

出现以下情况时，停止下一张并重做当前张：

  • 宫格或合集；
  • 数量错误；
  • 风格漂移；
  • IP 角色变脸；
  • 中级缩水严重；
  • 材质不明显；
  • 主题只换颜色；
  • 结构破碎；
  • 乱码影响主体；
  • 主体被裁切；
  • 安全区被占用。

重做提示必须强化：

本次只生成一个独立成品；严格保持角色脸型、眼型、发型和服装；不要其他角色；不要对比排版；不要文字；保持与上一张同一风格母体。

最多自动纠错 2 次。连续失败后必须如实指出失败点，不得虚假声称完成。

15. 参考图转译边界

可以提取：风格、材质、配色、结构骨架、主体特征和构图节奏。

不得复制：品牌 Logo、水印、原始文字、独特角色身份、完整构图和独特元素组合。

必须至少改变两项：主题、主体、动作、场景、构图、资产用途或装饰组合。

18. 最终自检

生成前：

  • 是否识别主裂变维度；
  • 是否建立风格母体；
  • 是否提取不可变核心；
  • 是否锁定数量与顺序；
  • 是否为每张建立独立任务。

生成后：

  • 数量完全正确；
  • 每张为独立图片；
  • 无宫格、无合集；
  • 风格统一；
  • 裂变差异真实；
  • IP 保持同一角色；
  • 中级保持完整；
  • 材质一眼可辨；
  • 画幅与背景正确；
  • 无水印、乱码和复制痕迹。

任一项不通过，先纠错再继续。

19. 最终执行口径

默认先执行风格锚定，再执行图片裂变。用户无需重复说“调用风格锚定 Skill”。

多张任务必须逐张独立生成；同系列任务必须保持同一风格母体、角色识别和结构骨架；主题、材质、主体或等级裂变时，只改变指定维度。

最终交付标准：

数量准确
顺序准确
单张输出
风格统一
差异明确
结构完整
商业可用
